# 지역 라디오

위치가 바뀌면 그 지역 FM 주파수로 자동으로 맞춰 주는 국내 라디오 앱입니다.
기독교·불교·천주교·원불교 방송과 클래식 채널은 넣지 않았습니다.

- `docs/index.html` : 웹 버전(주파수 안내, 위치 자동 감지)
- `app/` : 안드로이드 앱(인터넷 실시간 방송 재생, 안드로이드 오토 지원)
- `app/src/main/assets/stations.json` : 방송·지역·주파수·재생 주소 목록

## 1. 깃허브에 올리기

1. github.com 에서 새 저장소를 만듭니다(이름 예: `region-radio`).
2. 이 묶음의 압축을 풀고, 안의 파일 전체를 저장소에 올립니다
   (`.github` 폴더가 빠지지 않게 합니다. 웹 화면의 "uploading an existing file"로 끌어다 놓아도 됩니다).
3. 기본 브랜치 이름은 `main` 이어야 합니다.

## 2. 웹 버전 주소 만들기

저장소 Settings → Pages → Source 를 "Deploy from a branch", Branch 를 `main` / `/docs` 로 저장합니다.
1~2분 뒤 `https://(계정이름).github.io/(저장소이름)/` 주소가 열립니다.
휴대전화 브라우저에서 열고 위치 권한을 허용하면 이동에 따라 지역이 자동으로 바뀝니다.
공개 저장소여야 무료로 Pages 를 쓸 수 있습니다.

## 3. 안드로이드 설치 파일(APK) 받기

1. 파일을 올리면 Actions 탭에서 "설치 파일 만들기"가 자동으로 실행됩니다(5분 안팎).
2. 끝난 실행을 눌러 아래쪽 Artifacts 의 `region-radio-apk` 를 내려받습니다(깃허브 로그인 필요).
3. 압축을 풀어 나온 `app-debug.apk` 를 휴대전화에서 열어 설치합니다("출처를 알 수 없는 앱 설치" 허용 필요).
4. 다시 빌드한 파일로 바꿀 때는 서명이 달라져 기존 앱을 지우고 설치해야 합니다.

빌드가 빨간색으로 실패하면 실패한 단계의 오류 내용을 그대로 복사해 Claude에게 보여 주세요.

## 4. 안드로이드 오토에서 쓰기

플레이스토어에서 받은 앱이 아니면 오토에 기본으로는 표시되지 않습니다.

1. 휴대전화 설정 → 안드로이드 오토 → 맨 아래 "버전"을 여러 번 눌러 개발자 모드를 켭니다.
2. 오른쪽 위 점 세 개 → 개발자 설정 → "알 수 없는 출처"를 켭니다.
3. 차에 연결하면 미디어 앱 목록에 "지역 라디오"가 나옵니다.
4. 차에서 화면을 끈 채로도 지역이 자동으로 바뀌게 하려면 앱 아래쪽 버튼으로 위치를 "항상 허용"으로 바꿉니다.

## 알아 둘 점

- 소리는 FM 전파가 아니라 방송사 인터넷 실시간 방송입니다. 데이터가 쓰입니다.
- 재생 주소는 방송사가 공식 공개한 것이 아니어서 바뀌거나 막힐 수 있습니다.
  바뀌면 `stations.json` 의 `streamType` / `streamArg` 와 `StreamResolver.kt` 를 고칩니다.
- 지역 민영방송(TJB, KNN 등)과 지역 KBS·MBC 는 인터넷 재생 시 서울 본방송이 나옵니다.
- TBN, YTN, 경인방송, OBS 는 재생 주소가 없어 주파수만 안내합니다.
- 개인 사용을 전제로 만들었습니다. 배포하려면 방송사 이용약관을 확인해야 합니다.
